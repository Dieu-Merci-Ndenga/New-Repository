# Forge

A fast, local-first Git intelligence CLI.

---

## Why

Modern Git repositories contain years of history that are difficult to understand.

Forge helps developers understand code evolution, estimate change impact, explain historical decisions, and improve commit quality.

It is not another AI chatbot.

It is a deterministic Git analysis engine with optional AI explanations.

---

## Features (planned)

- Repository indexing
- Impact analysis
- Commit explanation
- Smart commit splitting
- Release intelligence
- Local-first architecture

---

## Design Principles

- Fast
- Local-first
- Deterministic
- AI optional
- Cross-platform
- Open Source
