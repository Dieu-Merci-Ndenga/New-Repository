# Vision

## Mission

Help developers understand repositories before modifying them.

---

## Problem

Git stores history.

It does not explain history.

Developers spend significant time understanding code evolution before making safe changes.

Forge solves this problem.

---

## Target users

- Solo developers
- Open-source maintainers
- Startup teams

---

## Non-goals

Forge is not:

- a Git client
- a code editor
- an IDE
- an autonomous AI agent
- another ChatGPT wrapper

---

## Core Principles

Local First

Fast

Deterministic

Composable

AI as an assistant—not the decision maker.

---

## Long-term Vision

Become the reference Git intelligence engine for developers.
